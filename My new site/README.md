# Портфолио Мирбека Салижанова

## Запуск
1. Распакуйте ZIP.
2. Откройте `index.html` в браузере (двойной клик). Сервер не нужен.
3. Шрифты подгружаются из Google Fonts (нужен интернет); без него используются системные.

## Структура
- `index.html` — разметка (header, nav, main, section, footer)
- `css/style.css` — стили, токены в `:root`
- `js/script.js` — вся логика
- `assets/avatar.svg` — портрет-заглушка (замените на своё фото)

## Функции JavaScript
1. `initTheme()` — светлая/тёмная тема, запоминание выбора
2. `initMenu()` — мобильное меню (клик, Escape, закрытие по ссылке)
3. `initModal()` — окно с подробностями проекта
4. `initForm()` — проверка формы с сообщениями об ошибках
5. (доп.) `initEffects()` — анимация имени, появление блоков, подсветка пункта меню

## Токены для Figma
Цвета: Orange #FF7A1A, Red #E5231B, White #FFFFFF, Cream #FFF4EC, Ink #2A1410, Dark BG #1B0D0A, Dark Card #2B1511
Градиент: 135°, Orange → Red
Шрифты: Unbounded 800/500 (заголовки), Manrope 400/500/700 (текст)
Размеры: H1 150/95%, H2 48, H3 19, текст 17/1.65, кнопки 16 bold
Отступы: 8 / 16 / 24 / 32 / 72, радиус карточек 20, кнопок 50
Макеты: Desktop 1440 (сетка 1200), Mobile 390 (поля 20)
